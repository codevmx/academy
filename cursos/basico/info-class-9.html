Tema 58

¿Qué son las herramientas de productividad?

Son programas que nos ayudan a hacer tareas de estudio y trabajo de forma más rápida y ordenada: escribir, calcular, presentar ideas.

Procesador de texto
Para escribir documentos: cartas, tareas, informes.
Hoja de cálculo
Para organizar datos y hacer cuentas.
Presentaciones
Para explicar ideas con diapositivas.
Dónde encontrarlas
Word, Excel y PowerPoint; Google Docs, Sheets y Slides; LibreOffice.

Tema 59

Procesadores de texto

Un procesador de texto es el programa con el que escribimos, corregimos y damos buena apariencia a un documento.

  • Ejemplos: Microsoft Word, Google Docs, LibreOffice Writer.
  • Corrige errores de ortografía automáticamente (subraya en rojo).
  • Permite cambiar letra, tamaño, colores y agregar imágenes.

Ejemplo práctico: conocer la pantalla

  • Hoja en blanco: donde escribes.
  • Barra de herramientas (cinta): botones para dar formato.
  • Cursor parpadeante: indica dónde aparecerá lo que escribas.

Tema 60

Crear documentos

Crear un documento es abrir una hoja nueva para empezar a trabajar.

Ejemplo práctico: crear un documento

  1. Abre el programa (por ejemplo Word o Google Docs).
  2. Elige Documento en blanco (o Archivo → Nuevo).
  3. Ya puedes escribir: se abre una hoja vacía lista para usar.

Atajo: Ctrl + N crea un documento nuevo.

Tema 61

Escribir y editar

  • Escribir: usa el teclado; Enter baja de renglón y Shift escribe mayúsculas.
  • Seleccionar: arrastra el mouse sobre el texto, o haz triple clic para un párrafo.
  • Editar: borrar, copiar, cortar, pegar y deshacer.

Ejemplo práctico: corregir un texto

  1. Selecciona una palabra mal escrita.
  2. Escribe la correcta (reemplaza lo seleccionado) o haz clic derecho y elige la sugerencia.
  3. Si te equivocas: Ctrl + Z deshace el último cambio.

Tema 62

Formato básico

El formato mejora la presentación del texto y facilita su lectura.

Negrita, cursiva, subrayado
Resaltan palabras importantes.
Tipo y tamaño de letra
Usa letras claras y legibles (por ejemplo, tamaño 12).
Alineación
Izquierda, centro, derecha o justificado.
Listas
Con viñetas o numeradas.

Ejemplo práctico: poner un título

  1. Escribe el título y selecciónalo.
  2. Aplica Negrita (Ctrl + B), aumenta el tamaño y elige Centrar.

Tema 63

Guardar documentos

Si no guardas, puedes perder tu trabajo (por ejemplo, si se va la luz). Guarda desde el principio y con frecuencia.

Ejemplo práctico: guardar por primera vez

  1. Presiona Ctrl + S (o Archivo → Guardar como).
  2. Elige dónde guardarlo (por ejemplo, la carpeta Documentos).
  3. Escribe un nombre claro, como Tarea_clase8, y pulsa Guardar.

Después, Ctrl + S solo actualiza el mismo archivo. Google Docs guarda automáticamente.

Tema 64

Imprimir y compartir

Imprimir
Pasa el documento al papel con una impresora.
Compartir
Enviarlo a otra persona de forma digital.

Ejemplo práctico: imprimir

  1. Presiona Ctrl + P.
  2. Revisa la vista previa, elige la impresora y el número de copias.
  3. Pulsa Imprimir.

Ejemplo práctico: compartir

  • Por correo: adjunta el archivo; conviene guardarlo también como PDF para que no se mueva el formato.
  • En línea: botón Compartir y escribe el correo de la persona (elige si puede ver o editar).

Temas 65 y 66

Hojas de cálculo y datos básicos

Una hoja de cálculo organiza información en filas y columnas y permite hacer cálculos automáticos.

  • Celda: cada casilla; se nombra con columna y fila (por ejemplo, B2).
  • Datos: pueden ser texto, números o fechas.
  • Ejemplos: Excel, Google Sheets, LibreOffice Calc.

Ejemplo práctico: sumar gastos

AB
1ConceptoMonto
2Transporte50
3Comida80
4Total=SUMA(B2:B3)

Al escribir =SUMA(B2:B3) y pulsar Enter, la celda muestra 130. Si cambias un monto, el total se actualiza solo.

Tema 67

Presentaciones

Una presentación es un conjunto de diapositivas para explicar un tema frente a un grupo o compartirlo.

  • Ejemplos: PowerPoint, Google Slides, LibreOffice Impress.
  • Cada diapositiva lleva poco texto, imágenes y títulos claros.

Ejemplo práctico: crear una presentación sencilla

  1. Abre el programa y elige Presentación en blanco.
  2. En la primera diapositiva escribe el título y tu nombre.
  3. Agrega otra con Nueva diapositiva: un título y 3 ideas cortas.
  4. Inserta una imagen y pulsa Presentar (o F5) para verla en pantalla completa.

Buena práctica: una idea por diapositiva y letra grande.
