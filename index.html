Exploradores Digitales es un programa de formación en informática diseñado para desarrollar y fortalecer las competencias tecnológicas de cada persona de acuerdo con sus conocimientos, experiencia, intereses y objetivos.

¿El programa está condicionado por edad o escolaridad?
No.
Cada participante es ubicado en un nivel de aprendizaje según un diagnóstico inicial.
El diagnóstico considera aspectos como
{ }Experiencia previa con la tecnología
{ }Formación académica
{ }Intereses personales
{ }Habilidades que desea fortalecer
{ }Hobbies
{ }Especialidad o área profesional
{ }Emprendimiento o proyecto de interés
{ }Objetivos personales o laborales

Así, cada participante inicia en el nivel que corresponde a sus conocimientos y avanza progresivamente conforme desarrolla nuevas competencias.

{ }

Un programa de tres niveles — Básico, Intermedio y Avanzado — cada uno con su propio enfoque y punto de partida. Cada participante inicia en el nivel que corresponde a su diagnóstico y cierra con un proyecto real como resultado.
